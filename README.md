# Digital Image Processing (CIMIT 5124)

This repository contains practical laboratory materials for Digital Image Processing, focusing on fundamental concepts, principles, and their implementation in Python.

## Laboratory Notebooks

| Lab | Notebook | Description |
|---|---|---|
| 01 | [Digital Image Fundamentals](01_digital_image_fundamentals.ipynb) | Image representation, pixel properties, spatial sampling, intensity quantization, and RGB channel decomposition. |
| 02 | [Arithmetic and Logical Operations](02_arithmetic_and_logical_operations.ipynb) | Image addition, subtraction, multiplication, division, overflow, normalization, logical operations, ROI masking, and difference detection. |
| 03 | [Gray-Level Transformations](03_gray-level_transformations.ipynb) | Linear transformations, contrast stretching, gray-level slicing, gamma correction, logarithmic transformations, and Fourier spectrum visualization. |

Follow the instructions in [setup.md](setup.md) to configure the Python environment and Jupyter Notebook in VS Code.
